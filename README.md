## Sobre mim

Sou estudante de **Engenharia de Software** e estou na fase mais divertida da jornada: a de descobrir do que eu gosto.

Ainda não tenho uma stack de domínio — e tudo bem. Meu foco agora é entender **fundamentos** (lógica, estrutura de dados, versionamento, como uma aplicação nasce e vai pro ar) em vez de colecionar frameworks. Cada repositório aqui é um exercício desse processo: código real, com erro, refatoração e aprendizado no meio.

- 🎓 Cursando Engenharia de Software
- 🌱 Aprendendo na prática, construindo projetos pequenos e melhorando aos poucos
- 🧭 Explorando as áreas de desenvolvimento até achar a que me pegar de vez
- 💬 Aberto a feedback, code review e trocar ideia sobre estudos
- ⚡ Curiosidade: acredito que ler código dos outros ensina tanto quanto escrever o seu
